Welcome to my Intermediate Java Programming repository! This repository contains my practice exercises, mini projects, and lab exams from my continued journey as a Computer Science student. It serves as a collection of my learning progress in applying intermediate Java concepts to build more complete, real-world systems.

## What you'll find here

| Category | Description |
|---|---|
| **Practice Exercises** | Programs that reinforce intermediate concepts like OOP, GUI development, and file-based CRUD operations. |
| **Projects** | Mini-systems that integrate multiple concepts into practical, working applications (e.g. reservation, inventory, and record-keeping systems). |
| **Lab Exams** | Timed lab activities and exam solutions completed under class conditions. |

## Topics covered

- Object-Oriented Programming (classes, objects, encapsulation, the `this` keyword)
- GUI Development with Java Swing (`JFrame`, `JTable`, `MouseListener`, `KeyAdapter`, `ActionListener`)
- File Handling (`BufferedReader`/`BufferedWriter`, read/write, CRUD operations)
- Arrays, ArrayLists, and multidimensional arrays
- Event-driven programming (lambda and anonymous `ActionListener` styles)
- Data validation (duplicate ID checking, date format validation)
- Basic input/output (`Scanner`, console-based programs)

- Hotel Room Reservation (console + GUI)

- Patient Record & Appointment Systems
- Vehicle / Car Rental System
- Food Order System (GUI)
- Employee Payroll & Management Systems
- Medicine Inventory, Sales Record, and Student Grades systems
