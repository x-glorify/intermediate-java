# Employee Payroll Management System

## Overview

A Java-based Payroll Management System developed using Object-Oriented Programming (OOP) principles. It provides a graphical user interface (GUI) for managing employee payroll information, with data stored persistently using file handling.

---

## Features

- Add employee payroll records
- Update existing employee information
- Delete employee records
- Calculate total salary based on hours worked and hourly rate
- Save and retrieve employee data using file handling

---

## Tools Used

- **Java** — core programming language
- **Java Swing** — GUI components (JFrame, JPanel, JTable, JTextField, JButton, etc.)
- **Object-Oriented Programming (OOP)** — encapsulation, constructors, getters, and setters
- **File Handling** — FileWriter, BufferedReader, BufferedWriter for persistent storage

---

## Project Structure

| File | Description |
|---|---|
| `Meneses_DepartmentalPractice.java` | Main GUI class — launches the application and handles all user interactions |
| `Payroll.java` | Model class — defines the Employee attributes, constructor, getters, and setters |

---

## How to Run

1. Open the project in Eclipse IDE or any Java IDE.
2. Compile all Java files.
3. Run `Meneses_DepartmentalPractice.java`.
4. Use the graphical interface to manage employee payroll records.

---

## Learning Objectives

This project demonstrates:

- Java GUI development using Swing with BorderLayout and GridLayout
- Object-Oriented Programming — encapsulation through private fields, constructors, getters, and setters
- Event-driven programming using ActionListener and MouseListener
- File handling for persistent data storage
- Basic payroll computation (Total Salary = Hours Worked × Hourly Rate)
